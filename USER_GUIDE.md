Smart Pantry Manager - User Guide

Purpose

Smart Pantry Manager helps users keep track of pantry ingredients and find recipes based on the ingredients they have available.

Using the Application

Managing Ingredients

Open the application.

Navigate to the ingredient management screen.

Enter the ingredient name, quantity and unit.

Save the ingredient.

View your saved ingredients and use the available options to manage them.

Finding Recipes

Open the recipe suggestions section.

View the recipes suggested by the application.

Select a recipe to view its details, if this option is available.

Data Storage

The application uses an SQLite database to store pantry information locally on the device.

Input Validation

The application checks ingredient information before saving it. Users should enter a name, a valid quantity greater than zero, and a unit.
